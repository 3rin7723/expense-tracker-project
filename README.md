# expense-tracker-project
Python expense tracker for Computer Programming project

## Group Members
- Erin – Add Expense Feature
- Lucia – View and Total Expense Features
- Carlie – Filter and Delete Expense Features

## Project Description
This Python program helps users track their expenses. Users can add expenses, view them, filter them by category, calculate the total amount spent, and delete specific expenses.

## Features
- Add new expense
- View all expenses
- Filter expenses by category
- Calculate total expenses
- Delete specific expenses

## How to Run the Program
1. Download the file `expense_tracker.py`
2. Open it in Python or VS Code
3. Run the program
4. Use the menu to manage expenses

## Reflection
One challenge in this project was combining everyone’s code into one program. We solved this by using GitHub branches and pull requests so each person could work on their own feature.

Another challenge was making sure the program handled invalid input correctly.
